# Sitio web corporativo de SoftTech

Sitio web de SoftTech S.R.L., empresa de desarrollo de software de Santa Cruz de la Sierra. Presenta a la empresa y su producto, el sistema Separador de Contenido de Videos (Karaoke), y atiende a sus usuarios.

## Funcionalidades

- Presentación de la empresa y de sus productos.
- Descarga de la aplicación móvil y de sus actualizaciones, con el historial de versiones.
- Preguntas frecuentes.
- Formulario de contacto que envía un correo a la empresa.
- Chat en vivo con el equipo.
- Agente inteligente que responde preguntas sobre la empresa y el producto.

## Tecnologías

- Laravel 12 (PHP 8.2 o superior) con vistas Blade.
- Tailwind CSS 4 y Vite.
- Gemini (Google AI Studio) para el agente inteligente.
- Tawk.to para el chat en vivo.
- Azure App Service para la publicación.
